================================================================================
  Niche Hunter Pro — إعداد النسخة المحمولة (Portable)
================================================================================

هذا المجلد يعمل على أي حاسوب Windows بعد نسخه كاملاً — بدون تعديل مسارات يدوية.

--------------------------------------------------------------------------------
1) نسخ المجلد
--------------------------------------------------------------------------------
  • انسخ المجلد بالكامل إلى أي مكان (مثال: D:\NHP أو سطح المكتب).
  • لا تغيّر أسماء المجلدات الداخلية (addon، native-host، ...).

--------------------------------------------------------------------------------
2) تثبيت Node.js (مرة واحدة على الجهاز)
--------------------------------------------------------------------------------
  • حمّل Node.js LTS من: https://nodejs.org/
  • أثناء التثبيت فعّل "Add to PATH".
  • للتحقق: افتح cmd واكتب: node -v

--------------------------------------------------------------------------------
3) تشغيل السيرفرات من مجلد addon
--------------------------------------------------------------------------------
  الطريقة الموصى بها — انقر مرتين:

      addon\01_Start_All\START_SERVERS.bat

  أو من PowerShell:

      addon\01_Start_All\START_SERVERS.ps1

  ماذا يفعل السكربت؟
  • يكتشف مسار المشروع تلقائياً (لا يحتاج تعديل مسارات).
  • يثبّت npm install تلقائياً إذا كان node_modules مفقوداً.
  • ينشئ .env من .env.example إن لم يكن موجوداً.
  • ينشئ addon\cliproxyapi-local\config.yaml من المثال إن لزم.
  • يشغّل كل السيرفرات في الخلفية.

  منافذ السيرفرات المحلية (127.0.0.1):
      3019 — TeePublic Ghost
      3020 — Creaty Signup
      3021 — Redbubble Ghost
      3022 — Amazon Ghost
      3023 — Pinterest Ghost
      3024 — Creaty Workflow Ghost
      3031 — AI Bridge
      8317 — CLIProxyAPI Local

  السجلات: server_logs\

  لإيقاف السيرفرات: addon\02_Stop_All\NHP_Stop_All_Servers_SilentCore.bat

--------------------------------------------------------------------------------
4) تحميل الإضافة في Chrome
--------------------------------------------------------------------------------
  1. افتح: chrome://extensions
  2. فعّل "وضع المطوّر" (Developer mode)
  3. احذف أي نسخة قديمة من نفس المجلد إن وُجدت
  4. اضغط "Load unpacked" واختر مجلد المشروع (الجذر الذي فيه manifest.json)
  5. بعد أي تعديل: اضغط Reload (↻) في chrome://extensions

--------------------------------------------------------------------------------
5) إعداد .env (اختياري)
--------------------------------------------------------------------------------
  • يُنشأ تلقائياً من .env.example عند أول تشغيل.
  • للتوليد بالصور عبر CLIProxy المحلي:
      CLIPROXY_BASE_URL=http://localhost:8317/v1
      CLIPROXY_IMAGE_MODEL=gpt-image-2
  • أضف مفاتيحك الخاصة في .env — لا تشارك هذا الملف.
  • راجع أيضاً: ENV_SETUP_AR.txt

--------------------------------------------------------------------------------
6) تشغيل السيرفرات من داخل الإضافة (اختياري)
--------------------------------------------------------------------------------
  إذا أردت أزرار "تشغيل السيرفر" من لوحة Admin داخل الإضافة:

  أ) بعد تحميل الإضافة، شغّل (مرة واحدة لكل جهاز — نقر مزدوج):
         addon\00_Register_Native_Messaging\Register_NHP_Native_Messaging_User.bat
     إذا فشل الاكتشاف التلقائي، مرّر معرّف الإضافة من chrome://extensions:
         addon\00_Register_Native_Messaging\Register_NHP_Native_Messaging_User.bat YOUR_EXTENSION_ID
     (البديل القديم: Register_NHP_Native_Messaging_User.cmd في جذر المشروع)

  ب) أو عيّن مسار المشروع يدوياً من Admin → إعدادات المسار.

  بدون هذه الخطوة: شغّل السيرفرات يدوياً عبر addon\01_Start_All\START_SERVERS.bat — وهذا كافٍ للاستخدام العادي.

--------------------------------------------------------------------------------
7) CLIProxyAPI — OAuth للتوليد بالصور (اختياري)
--------------------------------------------------------------------------------
  • افتح بعد تشغيل السيرفرات: http://127.0.0.1:8317/management
  • أضف حساب Codex/Gemini حسب حاجتك.
  • المفتاح الافتراضي المحلي: nhp-local-cliproxy-key

--------------------------------------------------------------------------------
المتطلبات
--------------------------------------------------------------------------------
  • Windows 10/11
  • Google Chrome
  • Node.js 18+ (LTS موصى به)
  • اتصال إنترنت (للمواقع الخارجية وCLIProxy السحابي إن استُخدم)

--------------------------------------------------------------------------------
قيود متبقية
--------------------------------------------------------------------------------
  • Native Messaging و protocol handlers تحتاج تسجيلاً محلياً بعد كل نسخ (خطوة 6).
  • معرّف الإضافة (Extension ID) يتغيّر إذا نُسخ المجلد لمسار مختلف.
  • Puppeteer قد يحمّل Chrome عند أول استخدام لبعض الميزات.
  • مجلد node_modules كبير — يُثبَّت تلقائياً أو انسخه مع النسخة لتسريع الإقلاع.
  • بيانات OAuth في addon\cliproxyapi-local\auths خاصة بالجهاز الأصلي — أعد ربط الحسابات على الجهاز الجديد.
