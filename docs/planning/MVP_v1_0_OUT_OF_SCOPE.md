# MVP v1.0 Out of Scope

## Deferred Items

### 1) Infrastructure Migration or Runtime Topology Redesign
- **reason for exclusion/deferment**: Baseline is locked and AR-05 freeze explicitly disallows infra/runtime redesign during MVP planning and delivery.

### 2) DNS/Caddy/Render Platform Re-architecture
- **reason for exclusion/deferment**: Not required to deliver the EP-301 user journey and introduces high operational risk outside MVP scope.

### 3) Baseline Vault or Secret Model Redesign
- **reason for exclusion/deferment**: Security/baseline structure changes are explicitly frozen and would expand scope beyond roadmap lock.

### 4) Non-Mailbox Product Flows (SEO/PNG/Unrelated Modules)
- **reason for exclusion/deferment**: These paths do not block the mailbox onboarding story and dilute focus from MVP completion criteria.

### 5) Advanced Supervisor Automation Beyond Assistive Recovery
- **reason for exclusion/deferment**: MVP requires deterministic rule-based completion; autonomous override behavior is deferred to later controlled evolution.

### 6) Broad UX Rebrand or Full Navigation Redesign
- **reason for exclusion/deferment**: MVP needs targeted journey clarity improvements, not platform-wide UI transformation.
