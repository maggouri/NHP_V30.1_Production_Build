# Version 1.1 Candidates

## Candidate Theme
Version 1.1 should extend MVP reliability and operator efficiency without changing the frozen baseline architecture.

## Candidate Items

### 1) Guided Recovery Enhancements
- Add clearer in-journey recovery playbooks for retryable and recoverable error categories.

### 2) Operational Insights for Mailbox Journey
- Introduce lightweight visibility for step timing, queue pressure, and failure categories to support faster triage.

### 3) Role Matrix Usability Refinement
- Improve admin/supervisor control discoverability while keeping strict authorization boundaries.

### 4) Batch Readiness Verification
- Enable controlled multi-mailbox verification workflows for operational teams.

### 5) Expanded Validation Coverage
- Add deeper edge-case validation scenarios and deterministic handling for uncommon session/data mismatch cases.

### 6) Documentation Maturity Upgrade
- Publish operator runbooks and troubleshooting references aligned to post-MVP field usage.

## Prioritization Note
Final 1.1 selection remains **TBD** and should be approved only after MVP v1.0 release-gate evidence is complete.
